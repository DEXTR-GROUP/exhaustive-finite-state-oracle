# EFSO E5-001 — Independent Transition Engine

**Статус:** RUNNING  
**Контрольная точка:** E5-001

## 1. Цель

Реализовать собственную детерминированную модель вычислительных переходов EFSO без импорта IUT, QWENRNS или внешнего numerical oracle.

## 2. Граница

Проверяется именно transition engine, а не conformance с IUT. Внешние reference не вызываются во время исполнения `src/efso_transition.py`.

## 3. Реализованный контур

```text
Operation
    ↓
IndependentTransitionEngine
    ↓
primitive / operator
    ↓
TransitionResult
```

Поддержаны:

```text
ADD
MUL
REDUCE
RMSNorm
Activation
MatMul
Softmax
RoPE
Attention
MLP
Residual
```

## 4. Проверяемые свойства

- явный набор операций;
- shape validation для векторных и матричных операций;
- детерминированный результат;
- детерминированный порядок композиции;
- отсутствие внешних runtime imports;
- собственная реализация Attention, MLP и связанных primitive semantics;
- воспроизводимое machine-readable evidence.
