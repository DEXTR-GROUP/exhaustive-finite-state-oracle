# E12-001 — Reproducible Verification Harness

**Статус:** RUNNING  
**Контрольная точка:** E12-001

## 1. Цель

Квалифицировать воспроизводимость полного текущего EFSO evidence contour на одном и том же исходном состоянии репозитория.

## 2. Объект

```text
src/efso_reproducibility.py
validation/e12_001_evidence.py
```

## 3. Метод

Один и тот же набор из десяти qualification commands запускается два раза последовательными независимыми subprocess-вызовами:

```text
E4
FM2-R4-002
R4-NUM-001
E5
E6
E7
E8
E9
E10
E11
```

Для каждого запуска фиксируются return code, SHA-256 stdout и SHA-256 stderr. После каждого полного прохода вычисляется канонический SHA-256 набора machine-readable evidence.

## 4. Условие закрытия

```text
all commands PASS in run 1
all commands PASS in run 2
return codes identical
stdout digests identical
stderr digests identical
evidence digest identical
qualification = PASS
```

## 5. Ограничение

E12 не доказывает математическую корректность самих qualification semantics. Он доказывает воспроизводимость уже определённого и исполняемого evidence contour. Новое изменение исходного дерева должно создавать новое evidence.
