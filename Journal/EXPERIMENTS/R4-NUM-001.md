# EFSO R4-NUM-001 — Exhaustive Numerical Conformance

**Статус:** RUNNING
**Контрольная точка:** R4-NUM-001

## 1. Цель

Сопоставить результат независимого EFSO numerical evaluator с независимым внешним QWENRNS batch oracle на каждом состоянии корректно определённого конечного R4 пространства.

## 2. Конечное пространство

```text
query[2]
key[2][2]
value[2][2]
каждый scalar ∈ {-1, 0, 1}

|F| = 3^10 = 59049
```

## 3. EFSO evaluator

```text
src/efso_r4_evaluator.py
```

Evaluator не импортирует QWENRNS и не вызывает внешний runtime.

## 4. Внешний witness

```text
DEXTR-GROUP/QWENRNS
validation/r4_attention_batch_oracle.py
```

Witness запускается только validation harness через subprocess. Он не является частью EFSO runtime.

## 5. Сравнение

Для каждого из 59049 состояний сравниваются два output scalar.

```text
abs/relative tolerance = 1e-12
```

Фиксируются:

- external output count;
- maximum absolute error;
- mismatch count;
- первый counterexample при FAIL;
- canonical state digest.

## 8. Ограничение

Эта проверка квалифицирует только определённую primitive R4 Attention semantics на конечном пространстве. Она не доказывает correctness всего QWEN forward и не заменяет E5/E6.
