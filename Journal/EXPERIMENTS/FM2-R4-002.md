# EFSO FM2-R4-002 — R4 Semantic Shape Alignment

**Статус:** RUNNING
**Контрольная точка:** FM2-R4-002

## 1. Причина

В ходе подготовки E6 обнаружено, что текущий structural placeholder `R4State(q, k, v)` с тремя векторами ширины 2 задаёт `3^6 = 729` состояний, но не соответствует форме независимого R4 Attention reference из QWENRNS.

Независимый reference использует:

```text
query = vector[2]
key   = matrix[2][2]
value = matrix[2][2]
```

То есть только эти входные данные содержат `2 + 4 + 4 = 10` конечных параметров.

## 2. Вопрос

Какая минимальная конечная модель состояния точно соответствует форме primitive Attention reference, сохраняя полностью конечный и воспроизводимый domain?
