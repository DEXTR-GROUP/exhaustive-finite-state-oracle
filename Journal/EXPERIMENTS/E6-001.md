# EFSO E6-001 — Exhaustive Conformance Contour

**Статус:** RUNNING  
**Контрольная точка:** E6-001

## 1. Цель

Квалифицировать общий механизм exhaustive conformance EFSO на полном конечном R4-space через независимое сравнение двух вычислительных путей.

## 2. Граница

E6-001 проверяет именно механизм exhaustive conformance. В качестве второго пути используется уже квалифицированный external-origin R4 witness. Это **не является утверждением о conformance конкретного IUT**.

IUT-specific E6 cases будут добавляться отдельно после определения соответствующего finite-state contract и adapter.

## 3. Реализованный контур

```text
FiniteStateSpace
      ↓
Exhaustive enumeration
      ├──────────────┐
      ↓              ↓
EFSO evaluator   external witness
      └──────┬───────┘
             ↓
     generic comparator
             ↓
     mismatch / counterexample
             ↓
          evidence
```

Реализован `src/efso_conformance.py`.

## 4. Проверяемые свойства

- полное число состояний;
- соответствие количества результатов количеству состояний;
- сравнение каждого состояния в deterministic enumeration order;
- exact comparison при `tolerance = 0`;
- заранее заданная numerical tolerance;
- shape mismatch detection;
- cardinality mismatch detection;
- first reproducible counterexample;
- maximum absolute error;
- machine-readable qualification result.

## 5. Qualification case

## 7. Ограничение

E6-001 не закрывает conformance конкретного IUT. Оно квалифицирует сам exhaustive conformance contour. Следующий IUT-specific case должен иметь собственные finite-state definition, adapter и evidence.
