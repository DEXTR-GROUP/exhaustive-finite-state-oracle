# E11-001 — External Witness Qualification Bridge

**Статус:** RUNNING  
**Контрольная точка:** E11-001

## 1. Цель

Квалифицировать границу между EFSO runtime и внешним numerical qualification witness.

## 2. Объект

`src/efso_bridge.py`

## 3. Граница

E11-001 проверяет только bridge boundary: canonical input encoding, отдельный subprocess execution, provenance фиксацию и mutation independence. Внешний witness не импортируется EFSO runtime.

## 4. Witness

```text
reference_id: QWENRNS-R4-BATCH
source: DEXTR-GROUP/QWENRNS/validation/r4_attention_batch_oracle.py
source blob SHA: e4fea00d58ee1fe8e22ce3d502bf6aac0bfdfdaf
mode: external-origin pinned snapshot
```

## 5. Qualification fixture

Три детерминированных R4 cases с тем же input schema, что используется R4 numerical contour.

## 6. Проверяемые свойства

- canonical input serialization;
- external witness execution через subprocess;
- отсутствие stderr/output protocol corruption;
- output cardinality соответствует input cardinality;
- output digest воспроизводим;
- преднамеренная мутация копии EFSO evaluator не изменяет external witness output;
- provenance source identifier фиксирован.

## 7. Условие закрытия

```text
pytest PASS
evidence generated
mutation_independent = true
output_count_before == output_count_after
output_digest_before == output_digest_after
qualification = PASS
```

## 8. Ограничение

E11-001 не является новой numerical correctness qualification R4. Численная корректность R4 уже квалифицирована R4-NUM-001 на полном пространстве `59049`. E11 квалифицирует именно изоляцию и воспроизводимость external qualification bridge.
