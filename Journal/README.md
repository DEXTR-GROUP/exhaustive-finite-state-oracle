# EFSO — JOURNAL

Эта папка является нормативным журналом проекта `Exhaustive Finite-State Oracle`.

## Назначение

Journal фиксирует правила работы, текущее фактическое состояние, контрольные точки и результаты проверок EFSO.

Документы здесь создаются специально для EFSO. Из других проектов переносится только смысл соответствующих рабочих механизмов, а не их проектные формулировки, сущности или содержание.

## Нормативные документы

- `PROJECT_WORKING_PRINCIPLES.md` — канонические принципы разработки, проверки и фиксации EFSO;
- `МАЯК.md` — нормативная модель оперативной ориентации EFSO;
- `CURRENT_STATE.md` — текущий экземпляр состояния проекта;
- `EXPERIMENTS/EXPERIMENT_PROTOCOL.md` — нормативный протокол оформления отдельных проверок;
- `EXPERIMENTS/EXPERIMENTS.md` — реестр проверок и их статусов.

## Иерархия

```text
ДОРОЖНАЯ_КАРТА.md
        ↓
PROJECT_WORKING_PRINCIPLES.md
        ↓
МАЯК.md
        ↓
EXPERIMENT_PROTOCOL.md
        ↓
отдельные результаты / evidence
        ↓
CURRENT_STATE.md
```

Дорожная карта определяет последовательность этапов. Принципы определяют правила работы. МАЯК определяет текущую точку движения. Протокол определяет форму отдельных проверок. Реестр обеспечивает навигацию.

## Источник истины

Фактическое состояние EFSO определяется содержимым репозитория `main`, committed source и воспроизводимым evidence. Journal документирует состояние, но не может подменять фактическую проверку.
