# Следующий этап qualification

После structural FM0–FM3 baseline следующий обязательный контур:

1. подключить независимый R4 reference как внешний witness;
2. exhaustive enumerate заявленное R4 finite space;
3. сравнить EFSO output с независимым R4 output;
4. сохранить machine-readable evidence;
5. только после PASS переходить к R5.

NumPy float64 остаётся отдельной numerical qualification axis. Он не является частью EFSO runtime и не трактуется как exact real arithmetic.
