# EFSO FM2-R4-002 — R4 Semantic Shape Alignment

**Статус:** PLANNED
**Контрольная точка:** FM2-R4-002

## 1. Причина

В ходе подготовки E6 обнаружено, что текущий structural placeholder `R4State(q, k, v)` с тремя векторами ширины 2 задаёт `3^6 = 729` состояний, но не соответствует форме независимого R4 Attention reference из QWENRNS.

Независимый reference использует:

```text
query = vector[2]
key   = matrix[2][2]
value = matrix[2][2]
```

То есть только эти входные данные содержат `2 + 4 + 4 = 10` конечных параметров до учёта дополнительных конфигурационных параметров.

## 2. Вопрос

Какая минимальная конечная модель состояния точно соответствует семантике primitive Attention reference, сохраняя полностью конечный и воспроизводимый domain?

## 3. Требование

До начала R4 numerical conformance необходимо:

1. определить точную форму `R4State`;
2. определить finite domain каждого параметра;
3. вычислить exact cardinality;
4. проверить canonical identity;
5. построить exhaustive enumeration;
6. независимо сопоставить evaluation semantics с reference;
7. не смешивать structural enumeration с numerical reference.

## 4. Ограничение

Историческая запись `FM2-R4-001 = PASS` не переписывается. Её scope трактуется как structural qualification ранее определённого placeholder-space. Она не используется как доказательство numerical R4 semantics.

## 5. Условие закрытия

`FM2-R4-002 = PASS` только после появления воспроизводимого evidence, подтверждающего соответствие конечной модели фактической форме независимого R4 reference.
