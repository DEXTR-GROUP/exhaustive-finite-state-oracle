# R6-NUM-001 — Exhaustive numerical qualification R6

**Статус:** RUNNING  
**Контрольная точка:** R6-NUM-001

## 1. Цель

Провести state-by-state numerical conformance между независимым EFSO R6 evaluator и external-origin QWENRNS batch witness.

## 2. Конечное пространство

Минимальный Transformer Block из внешнего R6 reference contract использует два токена и hidden size 2.

Перебираются:

```text
input[4]
attention_update[4]
```

Каждый из 8 скаляров принимает значения `{-1, 0, 1}`. `epsilon = 1e-6` фиксирован и не является параметром конечного пространства.

```text
N = 3^8 = 6561
```

## 3. Независимость

EFSO не импортирует QWENRNS oracle. External witness запускается отдельным subprocess и получает только сериализованное описание конечных состояний.

Для CI используется source-exact pinned snapshot external-origin witness. Snapshot закреплён по исходному QWENRNS commit и Git blob SHA.

```text
QWENRNS source commit:
a40bdbfd999535f2bb9c57da6f2a2e861e49c12c

QWENRNS source blob:
dcea89f0c6246d1f466a91f696c3091d8e9c8948
```

## 4. Сравнение

Для каждого из 6561 состояний сравниваются четыре выходных значения.

```text
abs(EFSO(S)[i] - witness(S)[i]) <= 1e-12
```

Перед сравнением harness проверяет source blob SHA локального snapshot.

## 5. Условие закрытия

```text
6561 EFSO states
6561 external outputs
mismatch_count == 0
max_abs_error <= 1e-12
machine-readable evidence generated
CI PASS
artifact uploaded
```

## 6. Ограничение

Результат относится только к явно определённому конечному R6 qualification space и не является exhaustive claim для полного Transformer Block большой модели.

## 7. Текущее состояние

Статус `RUNNING` установлен до первого фактического CI numerical evidence. `PASS` допускается только после успешного выполнения полного контура.
