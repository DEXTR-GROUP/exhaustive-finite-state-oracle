# EFSO E4-001 — Exhaustive Enumerator Evidence

**Статус:** RUNNING
**Контрольная точка:** E4-001

## 1. Вопрос

Может ли EFSO исчерпывающе перечислить явно заданное конечное пространство без пропусков и дубликатов, с детерминированным порядком и воспроизводимым результатом?

## 2. Конечное пространство

`E4-BASE-3x3`

```text
a ∈ {-1, 0, 1}
b ∈ {-1, 0, 1}
|F| = 3 × 3 = 9
```

Каноническая идентичность состояния задаётся `state_id` из `src/efso_fm03.py`.

## 3. Проверяемые свойства

- `observed_count == expected_count`;
- `unique_count == expected_count`;
- `duplicate_count == 0`;
- `missing_count == 0`;
- детерминированный порядок повторного перечисления;
- точная воспроизводимость enumeration;
- стабильный SHA-256 digest последовательности state IDs.

## 4. Реализация

Основной enumerator:

```text
src/efso_exhaustive.py
```

Тесты:

```text
tests/test_exhaustive.py
```

Machine-readable evidence generator:

```text
validation/e4_001_evidence.py
```

CI должен одновременно выполнить тесты, сформировать `evidence/e4_001.json` и сохранить его как workflow artifact `efso-e4-001-evidence`.

## 5. Критерий закрытия

E4-001 может перейти в `PASS` только при наличии фактического CI run, в котором:

1. все тесты проходят;
2. evidence generator завершается успешно;
3. machine-readable evidence сформировано;
4. artifact доступен в workflow run.

## 7. Ограничение

E4-001 подтверждает свойства exhaustive enumeration на пространстве `E4-BASE-3x3`. Он не является numerical conformance test и не доказывает соответствие R4/R5/R6/R7 или IUT.
