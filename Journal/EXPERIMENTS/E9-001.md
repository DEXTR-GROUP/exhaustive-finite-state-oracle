# E9-001 — Machine-Readable Conformance Coverage Matrix

**Статус:** RUNNING  
**Контрольная точка:** E9-001

## 1. Цель

Квалифицировать машиночитаемую матрицу покрытия EFSO, которая явно различает structural и numerical qualification и фиксирует объём проверенного конечного пространства.

## 2. Объект

`src/efso_matrix.py`

## 3. Проверяемые поля

```text
space_id
operator
reference_id
qualification_type
cardinality
expected_count
enumerated
unique
missing
duplicates
passed
failed
witness
```

## 4. Проверяемые свойства

- полная запись cardinality;
- distinction structural/numerical;
- отсутствие дублирующих строк;
- отсутствие partial coverage;
- deterministic row order;
- canonical machine-readable serialization.

## 5. Qualification fixture

```text
space: R4-DOMAIN-3^10
cardinality: 59049
rows: 5
structural rows: 3
numerical rows: 2
expected failed rows: 0
expected duplicate rows: 0
```

## 6. Условие закрытия

```text
pytest PASS
matrix qualification PASS
qualified_rows == row_count
failed_rows == 0
duplicate_space_rows == 0
deterministic_serialization == true
evidence generated
```

## 7. Ограничение

E9 квалифицирует механизм представления и проверки coverage matrix. Наличие строки в матрице не заменяет первичное evidence соответствующей проверки.
