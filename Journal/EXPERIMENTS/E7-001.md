# E7-001 — Independent Exhaustive Invariant Engine Qualification

**Статус:** PASS  
**Контрольная точка:** E7-001

## Назначение

Квалифицировать независимый invariant engine на явно определённом конечном пространстве R4.

## Объект

`src/efso_invariants.py`

## Контур

Для каждого состояния конечного пространства проверяются четыре явно заданных инварианта:

1. `shape` — структурная форма R4State;
2. `finite_domain` — принадлежность всех скаляров домену `{-1, 0, 1}`;
3. `canonical_identity` — наличие канонического SHA-256 идентификатора;
4. `finite_output` — конечность и размер результата независимого R4 evaluator.

Дополнительно выполняется независимое воспроизведение полного перечисления через `replay_factory`.
