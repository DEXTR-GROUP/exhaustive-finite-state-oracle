# E8-001 — Independent Counterexample Engine Qualification

**Статус:** RUNNING  
**Контрольная точка:** E8-001

## 1. Цель

Квалифицировать независимый механизм извлечения и минимизации воспроизводимых контрпримеров.

## 2. Объект

`src/efso_counterexample.py`

## 3. Граница

E8-001 проверяет механизм counterexample generation на детерминированном конечном fixture. Он не является IUT-specific conformance claim.

## 4. Проверяемые свойства

- поиск первого расхождения в deterministic enumeration order;
- сохранение state, actual, expected и причины расхождения;
- deterministic shrinking;
- принятие первого failing shrink candidate;
- завершение minimization при отсутствии сохраняющего failure кандидата;
- воспроизводимость минимального witness;
- отсутствие случайности и external runtime dependency.

## 5. Qualification fixture

```text
state domain: 0..7
initial failure witness: state-7
failure predicate: state.value >= 4
expected minimal witness: state-4
```

## 6. Условие закрытия

```text
pytest PASS
evidence generated
first failure reproducible
minimal witness = state-4
second minimization replay identical
qualification = PASS
```

## 7. Ограничение

E8 квалифицирует общий механизм counterexample extraction/minimization. Следующие E8 cases должны применять его к реальным conformance/invariant failures.
