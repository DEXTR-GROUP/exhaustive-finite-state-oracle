# EFSO — R4 Finite-State Qualification 001

**ID:** FM2-R4-001  
**Статус:** PASS  

## Цель

Создать первое формально заданное конечное qualification space для R4, которое EFSO может исчерпывающе перечислить без импорта R4 reference implementation.

## Space

```text
values = {-1, 0, 1}
vector width = 2
q ∈ values²
k ∈ values²
v ∈ values²
```

Следовательно:

```text
|F| = 3^(2×3) = 729
```

## State identity

```text
R4State(q, k, v)
```

Каноническое JSON-кодирование + SHA-256 используются для стабильной identity.

## Enumeration

Enumeration задаётся декартовым произведением конечных доменов и в тестах проверяется:

```text
observed = 729
unique = 729
```

## Independence

`src/efso_r4_qualification.py` не импортирует R4 oracle и не вызывает IUT.

Внешний reference подключается только как artifact по `state_id -> expected output`.

## Comparison policy

Базовый протокол допускает:

```text
abs_tol = 1e-6
rel_tol = 1e-6
```

Значения tolerance являются частью протокола и не меняются по результату конкретного запуска.

## Limitations

Текущий run квалифицирует finite-space construction, canonical identity и exhaustive enumeration model. Полное численное сравнение с реальным R4 reference требует генерации независимого reference artifact из QWENRNS и отдельного execution run.
