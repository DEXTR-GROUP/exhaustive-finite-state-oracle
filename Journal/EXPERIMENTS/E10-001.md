# E10-001 — Adversarial Exhaustive Finite Spaces

**Статус:** RUNNING  
**Контрольная точка:** E10-001

## 1. Цель

Квалифицировать набор adversarial finite spaces, ориентированных на граничные, вырожденные, симметричные и знаковые классы состояний.

## 2. Объект

`src/efso_adversarial.py`

## 3. Базовое пространство

```text
R4-DOMAIN-3^10
cardinality = 59049
```

## 4. Adversarial spaces

```text
R4-ADV-ALL-ZERO
R4-ADV-ALL-NEGATIVE
R4-ADV-ALL-POSITIVE
R4-ADV-BOUNDARY
R4-ADV-ZERO-QUERY
R4-ADV-SYMMETRIC-ROWS
R4-ADV-MIXED-SIGN
```

Каждое пространство задаётся явным predicate и полностью перечисляется поверх базового конечного пространства.

## 5. Условие закрытия

```text
pytest PASS
expected cardinality == observed cardinality for every space
unique_count == expected cardinality
replay deterministic
machine-readable evidence generated
qualification = PASS
```

## 6. Ограничение

E10 проверяет именно adversarial finite-space machinery. Он не заменяет numerical conformance и не является утверждением о произвольном IUT.
