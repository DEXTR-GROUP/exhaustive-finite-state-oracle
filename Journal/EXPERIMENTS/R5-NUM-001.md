# R5-NUM-001 — Exhaustive numerical qualification R5

**Статус:** RUNNING  
**Контрольная точка:** R5-NUM-001

## 1. Цель

Провести state-by-state numerical conformance между независимым EFSO R5 evaluator и external-origin QWENRNS batch witness.

## 2. Конечное пространство

```text
input[1]
gate_weight[2]
up_weight[2]
down_weight[2]
```

Каждый скаляр принимает значения `{-1, 0, 1}`.

```text
N = 3^7 = 2187
```

## 3. Независимость

EFSO не импортирует QWENRNS oracle. External witness запускается отдельным subprocess и получает только сериализованное описание конечных состояний.

External witness не импортирует EFSO, IUT и не вызывает Rust/Cargo runtime.

Для CI используется локальный immutable snapshot external-origin witness. Snapshot закреплён по исходному QWENRNS commit и Git blob SHA. Доступ CI к исходному приватному репозиторию не требуется.

```text
QWENRNS source commit:
4db6a1d314a1d0becb63995927feb90f301eb20e

QWENRNS source blob:
901125629523f473a597c9eeebdb8b6cb26a41d7
```

## 4. Сравнение

Для каждого состояния сравнивается единственный выходной скаляр.

```text
abs(EFSO(S) - witness(S)) <= 1e-12
```

Перед запуском сравнения harness проверяет, что локальный snapshot воспроизводит заявленный Git blob SHA. Фиксируются:

- число состояний;
- число external outputs;
- `mismatch_count`;
- `max_abs_error`;
- первый mismatch;
- digest последовательности state IDs;
- digest external output;
- provenance исходного witness;
- digest snapshot.

## 5. Условие закрытия

```text
2187 EFSO states
2187 external outputs
mismatch_count == 0
max_abs_error <= 1e-12
machine-readable evidence generated
CI PASS
```

## 6. Ограничение

Результат относится только к явно определённому конечному R5 qualification space и не является exhaustive claim для полного MLP большой модели.

## 7. Инфраструктурное решение

Предыдущий CI checkout `DEXTR-GROUP/QWENRNS` был удалён из verification path после подтверждённого `Repository not found` на runner. Замена на другой внешний oracle не выполнялась. Вместо этого используется pinned snapshot исходного QWENRNS witness с проверяемым provenance.
